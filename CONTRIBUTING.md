# Contributing to Birdie

[中文](#中文)

**For now, Birdie does not accept code contributions (pull requests).** Pull requests will be closed with a
pointer to this page. This may change later; if it does, this page will say so.

What is very welcome:

- **Bug reports** — open an [issue](https://github.com/Xuan0876/birdie-hud/issues) with what you did, what you
  expected, what happened, your aircraft, screen size and Birdie version, and attach `%APPDATA%\Birdie\birdie.log`.
  A screenshot or a short clip of the HUD helps a lot.
- **Ideas** — also as an issue. Birdie does one thing, the HUD ([docs/ROADMAP.md](docs/ROADMAP.md)), so ideas
  that make the HUD more accurate, nicer, easier to use or work on more aircraft fit best.

If a pull request shows a good fix, the maintainer may reimplement the idea and thank you in the commit.

Birdie is GPL-3.0: you are free to fork it, change it and publish your version under the same license.

## 中文

**Birdie 暂时不接受代码贡献（PR）。** 收到的 PR 会附上本页链接后关闭。以后可能会改，改的话这里会写明。

非常欢迎：

- **报告 bug**：开一个 [Issue](https://github.com/Xuan0876/birdie-hud/issues)，写清楚做了什么、预期是什么、实际怎样、机型、
  屏幕尺寸和 Birdie 版本，并附上 `%APPDATA%\Birdie\birdie.log`。有 HUD 的截图或短视频更好。
- **提建议**：同样开 Issue。Birdie 只做 HUD 这一件事（[docs/ROADMAP.md](docs/ROADMAP.md)），能让 HUD 更准、更好看、更好用或支持更多机型的建议最合适。

如果某个 PR 里有好的修复，维护者可能会参考思路自己重新实现，并在提交里致谢。

Birdie 按 GPL-3.0 开源：你可以自由 fork、修改，并按同一许可证发布你的版本。
