# 发布前实机测试（0.9.1-beta）

目的：用发布用的 zip，像新用户一样装一遍、飞一遍。离线能测的都测过了（见最后一节），这里只列必须开模拟器的。

## 准备

1. 退出正在运行的旧 Birdie（托盘右键 → 退出）。
2. 模拟新用户：把 `%APPDATA%\Birdie\settings.json` 改名（例如 `settings.old.json`），测完再改回来。
3. 把 `dist\Birdie-0.9.1-beta.zip` 解压到一个新文件夹（例如 `D:\BirdieTest`）。
4. MSFS 2024 无边框或窗口化，ChasePlane 驾驶舱视角。

## A. 安装和第一次运行

| # | 做什么 | 正常的样子 |
|---|---|---|
| A1 | 双击 `Birdie.exe` | 可能弹出 SmartScreen："更多信息"→"仍要运行"能过；托盘出现小鸟，气泡提示一次 |
| A2 | 第一次运行 | 设置窗口自动打开，首页顶上是欢迎卡片（要 ChasePlane、窗口化、开关热键、托盘小鸟、游戏内面板） |
| A3 | 在欢迎卡片里装游戏内面板 | 显示"已安装"，路径是你真正的 Community 文件夹 |
| A4 | 重启模拟器 | 工具栏里有小鸟；打开后能连上 Birdie，改设置后 HUD 立刻跟着变 |
| A5 | 已经装过旧面板的情况 | 新版启动时自动把面板换成新的，设置里有提示；重启模拟器后是新面板 |

## B. 飞一次起降

| # | 看什么 | 正常的样子 |
|---|---|---|
| B1 | 起飞滑跑 | 40 kt 以上 HUD 出现；切外部视角、转头看侧面、切到别的窗口时 HUD 消失 |
| B2 | 按 ESC 暂停 | HUD 隐藏或停住，回来后恢复 |
| B3 | 进近 | 日志里有 `[rwy] selected ...`；跑道框贴住道边，接地区标志在道面上；下滑线压在瞄准点 |
| B4 | 速度 / RA 读数 | 按"自动显示 / 隐藏"的设定出现和消失 |
| B5 | 50 ft 以下 | 小鸟上方闪 + / ++ 拉平提示 |
| B6 | 落地 | 落地后地面滑行时 HUD 的表现符合设置 |

## C. 设置

| # | 做什么 | 正常的样子 |
|---|---|---|
| C1 | 三种界面风格来回切换（默认 / 浅色 / 黄昏） | 桌面窗口和游戏内面板都跟着变，没有错位 |
| C2 | 面板默认大小 | 第一次打开的大小合适，不用手动拉 |
| C3 | 改快捷键 | 新热键生效，旧热键失效 |
| C4 | HUD 边框：在画面上描一次 | 边框贴住挡风玻璃，超出部分淡出；换另一侧座位时用镜像 |
| C5 | 退出再开 | 设置都还在 |

## D. 验证线 A（其他屏幕和机型，能做多少做多少）

| # | 做什么 | 正常的样子 |
|---|---|---|
| D1 | 16:9 或 16:10 窗口（把 MSFS 窗口化调成 1920×1080 也行） | 跑道框和小鸟对得上画面，改 ChasePlane 缩放后仍然对得上 |
| D2 | Fenix A320/A321、FSLabs A321 进近 | 跑道框左右不偏（眼点横向只在 FBW 上验证过） |
| D3 | 新机型第一次停稳 | RA 自动校准，日志里有记录 |

## E. 卸载

| # | 做什么 | 正常的样子 |
|---|---|---|
| E1 | 设置 → 细调 → 游戏内面板 → 移除 | Community 里的 `birdie-panel` 没了（如果是链接，只删链接） |
| E2 | 测完 | 把 `settings.old.json` 改回 `settings.json` |

有问题的话把 `%APPDATA%\Birdie\birdie.log` 发出来，说一下第几项、什么样子。

## 已经离线验证过的（不用测）

- `ctest`：单元测试、面板协议、和参照版逐像素对照（9 张图）。
- `--replay tests\fixtures\lax_dusk_07L`：回放 LAX 进近，选中 07L，按规则显示 / 隐藏。
- 面板安装：导出的文件和源文件逐字节相同；覆盖旧版时会删掉多余文件；遇到不是 Birdie 的同名文件夹拒绝；链接（junction）时写进链接目标，移除时只删链接。
- 预览里小鸟对准瞄准点。
- 不开模拟器也能正常启动；第二个实例会提示"已经在运行"。
