# 别家工具栏面板怎么做的（11/17 调研）

看的是 MSFS 2024 Community 里装着的 9 个工具栏面板。只读它们的 CSS / HTML / .spb，没在模拟器里开。HudBar 是 WinForms 桌面程序，不是面板，没参考。

## 结论

1. **大家都留着模拟器自己的窗口框**（`ingame-ui` 的标题栏、关闭 / 最小化按钮），内容区才是自己的。只有 ChasePlane 是整页自己画（Vue），但仍然在 `ingame-ui` 里，标题栏背景设成透明。所以"像工具"的第一条：**看上去属于模拟器**——中性深灰、白字、一种亮色。
2. **ChasePlane 的样子**：
   - 底色是几乎没有色相的深灰，按钮从左上到右下有很轻的渐变（亮度 18% → 13%），边框是 1 px 的半透明线。
   - 只有一个强调色，金黄，表示选中和悬停。状态用红 / 绿 / 黄。
   - 零圆角，字是模拟器的字。
   - 字号随屏幕高度缩放（`calc(var(--screenHeight)*…px)`）。
   - 分区用带图标的类别（驾驶舱 / 外部 / 世界）。
3. **字号和控件**：都偏小、偏密；开关大多是模拟器的 `toggle-button`，滑块是 `range`。我们的面板自己画控件（Coherent 里也一样），**不用换**，只改配色和形状，让它和这些面板放在一起不突兀。
4. **反面**：TouchdownFX、Navigraph 用了蓝色调和圆角，看上去像网页而不像模拟器——这正是用户说的"深蓝科技风"，不学。
5. **默认窗口大小**：
   - 宽、高的数值是同一种单位。ChasePlane 是 60 × 60，那如果单位是"屏幕宽的百分比"，它会占半个屏幕宽，显然不是。所以**宽很可能也按屏幕高度算**。
   - 按这个理解，Birdie 现在是 14.5 × 36：2560×1440 下宽只有约 209 px，正好是用户说的"第一次打开太小"。
   - 详见 STATUS 第 5 项。

## 用到 Birdie 上

- **默认风格"工具"**：
  - 底色：中性近黑灰 `#1c1c1d`，分区线是半透明白。
  - 文字：主文字 `#e6e6e6`，次要文字 `#8d8d8f`。
  - 强调色：一种暖金黄 `#f0c330`，向 ChasePlane 靠，又不完全一样。
  - 零圆角；字只用无衬线（Jost / 思源黑体），数字用直立的等宽数字。
  - 开关和选项用实心方块 + 细边框，像模拟器的按钮。
  - 文案直说状态。
- **我们自己的设计感**：
  - 留着小鸟标志和 HUD 绿预览。
  - 发丝线和留白。
  - 选中项下面是一条从中间长出来的短线（原来的动效保留，换颜色）。
  - 标题用小号大写字母、加宽字距，像仪表上的标签。
