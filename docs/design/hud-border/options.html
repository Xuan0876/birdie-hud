BIRDIE · HUD 边框

别让 HUD 越过窗框 — options

示意图，不是真机比例。黄昏座舱是假的，绿色符号按 Birdie 现有的画法摆的。

0先说一个发现

Birdie 现在已经把整幅 HUD 裁在一块“合像镜”里：FBW 的 1280×1024 画布 = 左右 ±17.5°、机身纵轴上 9°、下 19°，跟着机身走（转头、改缩放都对得上）。真空客 HUD 的合像镜视场也差不多是这么大（约 35°×26°）。所以“模仿合像镜固定视场”其实就是现状。

超出窗框，是因为在你的眼点下，这块 35°×28° 比挡风玻璃大，多半是下沿压到遮光板（画布往下伸到 19°），转头时也可能压到窗柱。要解决的是：让用户把这块“合像镜”收成自己座舱的形状。

1边框存成什么

存成相对机身的角度（就在现有合像镜那个平面上，和 HUD 大小无关），不存屏幕像素。好处：

  • ChasePlane 改缩放、换窗口大小、16:9 / 21:9，都用现有相机模型投影回屏幕，自动对上。
  • 转头（Birdie 允许左右 45°、上下 40° 内照常显示）时，窗框和边框一起在画面里移动，仍然贴合。
  • 按机型存（SimConnect TITLE，和 RA 校准一样）、再按座位分左右；只描了一边时，另一边按左右镜像用（FBW 机长 −0.59 m / 副驾 +0.60 m 是对称的）。

限制：角度是“从这个眼点看过去”的。如果在 ChasePlane 里把眼点前后上下挪了不少（> 5–10 cm），窗框的角度会变，要重描。Birdie 可以记下描的时候的眼点，差太多时在面板里轻轻提一句。

2边框的形状

C 自动识别窗框

思路：头不动时座舱像素不变、窗外在变，几秒累积就能分出窗外。难点：夜里和云里窗外也不动、也是黑的；ChasePlane 的头部晃动、G 力会让座舱一起动；玻璃反光；座舱遮罩只在地平线以下才分得清（跑道实验踩过）。做得出来，但不稳，只适合当“描边时吸附到窗框”的辅助，不建议做第一版。

推荐 B，并且把 A 当成 B 的起点：一个模型（多边形），打开就是现在的四个角，拖角就能收；需要时点边线加点。用户不用在“简单 / 精细”之间先做选择。

3在哪里编辑

推荐两者配合：细调页加一行“边框 ›”，进去是上面这样一页（入口、镜像、清除、羽化宽度），真正的描边在画面上做。只有滑块的话就只能是 A；只在画面上做的话，工具栏面板里也得有个入口按钮，否则找不到。

4边缘

实现：Direct2D 的 PushLayer 本来就支持“不透明度画刷”，把多边形填白、高斯模糊一下当画刷就行，GPU 上几乎不花时间。边框关着时一条新命令都不发，对照测试逐像素不变。

5出了边框的符号

转头时 HUD 本来就有规则：左右超过 45°、上下超过 40° 整幅藏起来。这一条不变；边框只管还在显示的时候。

·我的推荐合在一起

  • 边框 = 机身角度里的多边形，默认 = 现在的合像镜四个角；按机型 + 座位存，另一座位镜像。
  • 覆盖层上描（拖角、点边加点），设置窗口和工具栏面板细调页里有入口、镜像、清除、羽化宽度。
  • 向内羽化约 1°。
  • 所有符号一样淡出（a），描边时裁到仪表就提示并给“缩到放得下”；小鸟钉边（c）可以作为同一项里的一个小细节，也可以以后再说。
