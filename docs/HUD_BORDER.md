## 背景（为什么会超出）

Birdie 现在已经把整幅 HUD 裁在一块"合像镜"里：FBW 的 1280×1024 画布 = 左右 ±17.5°、机身纵轴上 9°、下 19°（`scene.cpp` 的 `scene.clip`，`canvas_pix` 投影，跟着机身走，随 `hud_scale` 一起缩）。真空客 HUD 的视场也大约是 35°×26°，所以"模仿合像镜固定视场"就是现状。超出窗框是因为在用户的眼点下，这块比挡风玻璃大（推测主要是下沿压到遮光板，转头时可能压到窗柱；**用户没说具体是哪一边，实现后飞一次看**）。

## 用户定的（11/17，逐项选的）

| 项 | 选定 | 没选的 |
|---|---|---|
| 形状 | **多边形，默认 = 现在合像镜的四个角**；拖角就是"简便"，要贴窗柱再在边上加点 | 只要四条边；先四边以后再多边形 |
| 编辑 | **在模拟器画面上描 + 设置页入口**（细调页一行"边框 ›"，设置窗口和工具栏面板同一页） | 只在画面上描（按键做镜像/清除）；再加上下左右四个滑块 |
| 边缘 | **向内羽化，固定 1°**（离边界 1° 开始淡出，到边界正好为 0，框外一点不露；没有滑块） | 宽度可调；硬裁 |
| 出界符号 | **a 全部一样淡出**（保形符号和机体固定仪表一视同仁，同真合像镜）；描边时裁到仪表带 / 读数就提示，并给"缩到放得下"（调 `hud_scale`） | c 小鸟钉在边上画虚线；b 只裁保形符号 |
| 自动识别窗框 | 不做（夜里、云里窗外不动也是黑的；ChasePlane 头部晃动、G 力让座舱一起动；玻璃反光；遮罩只在地平线以下分得清） | 以后最多做成"描边时吸附到窗框边缘"的辅助 |

## 设计

### 数据

- 顶点存在**现有 HUD 画布那个平面**上（机身固定、透视投影下直线还是直线），单位"度"：`x = (u − CX) / ONE_DEG`（+ 右），`y = (BORE_Y − v) / ONE_DEG`（+ 上），**按 k = 1 算，和 `hud_scale` 无关**。投影回屏幕走 `Frame::canvas_pix` 同一条路（k 取 1）。所以改缩放、换窗口大小、16:9 / 21:9、转头（45° / 40° 以内照常显示）都自动对上。
- 按机型存（SimConnect TITLE，同 `ra_by_aircraft`），再按座位分左右：座位 = `eye_lateral_m(a_x, r_x)` 的正负。只描了一边时另一边用镜像（`x → −x`，顶点顺序反过来保持绕向）；面板里"镜像到另一座"是显式复制一份。
- 同时记下描的时候的眼点（横向 = `2·r_x − a_x`，以及 `a_y`、`a_z`）。当前眼点和它（或镜像）差超过约 10 cm 时，面板轻轻提一句"眼点和描的时候不一样，边框可能偏"；不自动停用。
- `settings.json`：

  ```json
  "border_by_aircraft": {
    "<TITLE>": { "L": { "pts": [[-17.5, 9.0], [17.5, 9.0], [17.5, -12.0], [-17.5, -12.0]], "eye": [-0.59, 0.0, 0.0] },
                 "R": null }
  }
  ```

  读入时钳制：3–32 个点、每个坐标 ±60°。缺键 = 没有边框。

### 绘制

- 裁剪 = 现有合像镜四边形 ∩ 边框多边形（两层 `PushLayer` 嵌套就是求交）。
- 羽化：新命令 `7 push feathered polygon clip  feather_px, n, x0 y0 …`（`5` 弹出）。D2D 里在一张遮罩位图上把多边形填白、再沿边描一圈宽 = 羽化宽度的透明线（COPY 混合，相当于内缩半个宽度），高斯模糊 σ ≈ 宽度 / 4（边界处 ≈ 2%、内侧 1° 处 ≈ 98%），当成 `PushLayer` 的不透明度画刷（`ID2D1ImageBrush` 包效果输出）；不行就整幅 HUD 画到离屏位图再用 AlphaMask 效果合成。
- 羽化宽度固定 1°，换成像素 = `f · π/180`（随缩放变，角度不变）。
- 悬停符号高亮（`append_commands` 叠第二遍）用同一个裁剪。闪字（左上角状态消息）不裁。
- **当前机型没有边框时一条新命令都不发** → 对照测试命令列表和图像逐像素不变。

### 编辑模式（在画面上描）

- 入口：细调页"边框 ›"里的"在画面上描"（设置窗口、工具栏面板都发 `{"type":"border","op":"edit"}`）。只在驾驶舱视角 + 有 ChasePlane 时能进；**忽略"地面慢速"隐藏**（描边多半是停在机位上做的），外部视角、暂停照旧不能进。
- 覆盖层暂时铺满模拟器客户区、接收鼠标和键盘（去掉 `WS_EX_TRANSPARENT`、拿前台；`compute_why` 把它当成模拟器在前台）；退出时恢复原来的盒子大小和穿透。
- 画面：HUD 按约 28% 不透明度画；框外罩一层暖色薄纱（`#1c1518` 55%）；边框线杏色 `#f2b48a` 1.2 px；顶点是空心小圆点（拖动中的那个实心 + 一圈淡光晕），不用圆角矩形；靠近边线时出现虚线小圆表示"点这里加一点"；底部一行提示（中英）："沿着窗框，把小点拖过去 / 右键删点 · Enter 存好 · Esc 不改"。进出时淡入淡出，不闪。
- 操作：拖顶点；点边线（6 px 内）插一点；右键顶点删除（至少留 3 个）；Enter 保存；Esc 放弃。没描过时起点 = 合像镜四个角（k = 1）。
- 屏幕 → 平面：像素反投影成相机射线，乘 `R_bcᵀ` 回机身，和平面 z = F_CANVAS 求交（射线朝后则不接受这一点）。
- 保存后检查机体固定仪表（速度带、高度带、坡度刻度、下方读数，按当前 `hud_scale` 和侧风模式的位置）有没有落到边框外 1° 羽化带里；有就在面板提示"速度带下端会被裁掉"，并算出能放下的最大 `hud_scale`（二分），给"缩到放得下"按钮。

### 设置页"边框 ›"

细调页加一行"边框 ›"，进去一页（v2 随身风格）：一行状态（机型 · 座位 · 已描 / 按另一座镜像 / 没设）、"在画面上描 ›"、"镜像到另一座"、"清除"（回到只有合像镜），以及上面的眼点提示和"缩到放得下"。没有羽化滑块。新文字要重跑 `scripts/make_panel.py`（字体子集），装进 Community 要等用户不飞的时候、重启模拟器后生效。

### 消息

- 面板 → Birdie：`{"type":"action","name":"border_edit"|"border_mirror"|"border_clear"|"border_fit"}`。
- Birdie → 面板（状态里，机型在 `status.aircraft`）：`"border": {"seat": "L"|"R", "state": "drawn"|"mirrored"|"none", "editing": bool, "can_edit": bool, "other_own": bool, "eye_moved": bool, "cuts_fixed": bool, "fit_scale": 0.85 | null}`。

### 不变的

- 转头隐藏规则（左右 > 45°、上下 > 40° 整幅藏）照旧；边框只管还在显示的时候。
- 合像镜裁剪照旧（边框只会更小）。
