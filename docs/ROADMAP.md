# 路线图

## 指导思想（最高优先级）

**只做这一个插件，只在 HUD 上改进，不扩张。**

- 新功能先问：它是不是让 HUD 本身更准、更好看、更好用，或者能在更多机型上用？不是就不做，或者明确写成"范围外"。
- 不做成平台：不做通用仪表读取、EFB、航图、飞行记录、通用覆盖层框架，不做别的插件的替代品。
- 基础设施（标定、配置、界面）只做到 HUD 用得上的程度。
- 维护者约定：发现越做越大时，要主动提醒。

## 一期：ChasePlane 用户（当前）

不需要标定：镜头角度、缩放、眼点都来自 ChasePlane。

- **M0 移交包** ✅
- **M1 C++ 核心对齐 Python 参照版** ✅：几何、绘制命令、9 张对照图逐像素一致（[CPP_PORT.md](CPP_PORT.md)）
- **M2 多屏幕 + 多机型核实**（进行中）：21:9 上 FSLabs A321、Fenix A321、FBW A32NX、C152 已实飞；还差 16:9 / 16:10 下的缩放换算、
  Fenix / FSLabs 的眼点横向（目前只在 FBW 上验证过）、瞄准点标志的前后位置（和地景差约半块，待实测）
- **M3 游戏内工具栏面板** ✅：面板打进 `Birdie.exe`，设置里一键安装 / 更新 / 移除
- **M4 一期发布**（进行中）：
  - **测试版**：GitHub 开源，Releases 发预发布版（`0.9.x-beta`，HUD 上带测试版水印），通过 Issue 收反馈，有问题就出下一个 beta
  - **正式版 1.0.0**：M2 核实完、测试版稳定一段时间后发布（去掉版本后缀，水印随之消失），同一个 zip 发到 GitHub Releases 和 flightsim.to

一期不含飞行指引（FD）。

暂时不接受代码贡献（PR），欢迎通过 Issue 报告问题和提建议，见 [CONTRIBUTING.md](../CONTRIBUTING.md)。
