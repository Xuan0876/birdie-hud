# 路线图

## 指导思想（最高优先级）

**只做这一个插件，只在 HUD 上改进，不扩张。**

- 新功能先问：它是不是让 HUD 本身更准、更好看、更好用，或者能在更多机型上用？不是就不做，或者明确写成"范围外"。
- 不做成平台：不做通用仪表读取、EFB、航图、飞行记录、通用覆盖层框架，不做别的插件的替代品。
- 基础设施（标定、配置、界面）只做到 HUD 用得上的程度。
- 维护者约定：发现越做越大时，要主动提醒。

## 一期：ChasePlane 用户（当前）

不需要标定：镜头角度、缩放、眼点都来自 ChasePlane。

- **M0 移交包 + 私有仓库**（本仓库的初始状态）
- **M1 C++ 核心对齐 Python 参照版**，对照测试通过（[CPP_PORT.md](CPP_PORT.md)）
- **M2 多屏幕 + 多机型核实**：16:9 / 16:10 下缩放换算、Fenix / FBW / 原厂机眼点基准、RA 默认值、没有 ChasePlane 时明确提示
- **M3 游戏内工具栏面板**：MSFS 工具栏里调 HUD；参考开源工具栏面板的写法
- **M4 一期发布**：中英界面、单个 exe；S6 做完才开源（GitHub 转公开）并上架 flightsim.to，中间不发预览版

一期不含飞行指引（FD）。

## 二期：模拟器原生镜头

不装 ChasePlane 也能用。原生 `CAMERA GAMEPLAY PITCH YAW` 给俯仰/偏航；视场和眼点原生拿不到 → 需要标定（方案到时再选）。
